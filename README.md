# TVconnect — LAN Remote Desktop для Android TV / Google TV

Управление телевизором с Android TV с компьютера на Windows или Linux: изображение с экрана ТВ, мышь и клавиатура.
Работает **только в локальной сети**: без облака, relay-серверов и интернета.

```
┌──────────────── ПК (Windows / Linux) ───────────────┐        ┌──────────── Android TV ─────────────┐
│ TVconnect Desktop (Python + Qt6)                    │  LAN   │ TVconnect TV (Kotlin)               │
│  поиск ТВ · окно с экраном ТВ · мышь/клавиатура     │◄──────►│  MediaProjection → H.264 (MediaCodec)│
│  H.264-декодер (FFmpeg) · ADB-бэкенд                │ TCP    │  Accessibility-ввод · pairing        │
└─────────────────────────────────────────────────────┘ 47800  └──────────────────────────────────────┘
                                      (опционально: ADB по сети, порт 5555)
```

## Что умеет (Phase 1 + часть Phase 2, проверено на реальном ТВ)

| Функция | Статус |
|---|---|
| Поиск ТВ в сети: mDNS (`_tvconnect._tcp`) + UDP broadcast + ручной IP + устройства `adb devices` | ✅ |
| Сопряжение: подтверждение на ТВ + одинаковый 6-значный код на ТВ и ПК (защита от MITM) | ✅ |
| Доверенные ПК: токен (на ТВ хранится только SHA-256), запоминание ключа ТВ на ПК (pinning) | ✅ |
| Шифрование: ECDH P-256 → HKDF-SHA256 → AES-256-GCM для всего трафика | ✅ |
| Видео: MediaProjection → H.264 → TCP → FFmpeg; 540p / 720p / 1080p, 15 / 30 / 60 FPS, битрейт | ✅ |
| Клавиатура: стрелки, Enter, Esc(=BACK), Backspace, Delete, Tab, Home, End, F1–F12, медиа, громкость | ✅ (через ADB) |
| Кнопки ТВ на панели: BACK, HOME, MENU, OK, Recent, Vol±, Mute | ✅ |
| Мышь: клик=тап, удержание=long press, перетаскивание=свайп, колесо=прокрутка (или D-pad), ПКМ=BACK, СКМ=HOME | ✅ |
| **Общий буфер обмена**: Ctrl+V в окне ТВ вставляет текст с ПК в поле на ТВ (кириллица, эмодзи, многострочный текст); автосинхронизация буфера ПК → ТВ; Ctrl+C копирует выделенный текст / текст поля с ТВ на ПК | ✅ |
| Режим **ADB** (без TV-приложения): видео через `screenrecord`, ввод через `input`, вставка ASCII-текста | ✅ |
| Полноэкранный режим (Ctrl+F), FPS / разрешение / RTT / время декодирования в статус-баре | ✅ |
| Несколько ТВ одновременно (каждый в своём окне) | ✅ |
| Отключение клиента с ТВ, выключатель «Удалённое управление», удаление доверенных, автозапуск | ✅ |
| Логи: ПК — `%APPDATA%\TVconnect\logs`, `~/.config/tvconnect/logs`; ТВ — logcat + файл | ✅ |

**Проверено на:** Xiaomi Mi TV Stick (Android 11, API 30, Amlogic) + Windows 11 и Ubuntu 24.04 (WSL). Задержка RTT по Wi-Fi — 20–60 мс,
декодирование 1080p — 1.5–2.5 мс на кадр.

## Быстрый старт

1. **ТВ:** установите APK ([docs/BUILD.md](docs/BUILD.md#2-установка-apk-на-телевизор)) и откройте **TVconnect**.
   На экране появятся имя устройства, IP-адрес и статус «Ожидание подключения».
2. **ТВ (рекомендуется):** включите службу «TVconnect» в *Настройки → Спец. возможности*. Без неё доступны видео и громкость.
3. **ТВ (рекомендуется):** включите *Для разработчиков → Отладка по сети / Беспроводная отладка*. Нужна для всех клавиш
   (MENU, Tab, F-клавиши, D-pad на Android < 13), а на части прошивок — и для мыши.
4. **ПК:** запустите клиент ([инструкция](docs/BUILD.md#3-запуск-desktop-client)), выберите ТВ → **Подключить**.
5. При первом подключении сверьте код на ПК и ТВ и нажмите на ТВ **«Разрешить и запомнить»**.
6. На ТВ нажмите **«Начать»** в системном запросе на захват экрана. Android требует этого при каждом подключении.

## Два режима и почему их два

На Android обычному приложению **запрещено** вставлять в систему произвольные KeyEvent (это разрешено только системным
приложениям). Поэтому:

- **Native Agent Mode** (TV-приложение): видео через MediaProjection. Ввод идёт через AccessibilityService: жесты,
  BACK/HOME/Recent, D-pad (на Android 13+ нативно, на более старых — переносом фокуса), ввод текста в поле, громкость.
- **ADB Mode**: любые `KEYCODE_*`, тапы и свайпы через `adb shell input`. Видео — через `screenrecord`, без
  подтверждения на ТВ. Root не нужен.
- **auto** (по умолчанию): клавиши идут через ADB, если он доступен. Мышь и текст идут через Accessibility. Если прошивка
  отклоняет жесты Accessibility (так ведёт себя Mi TV Stick), клиент сам повторяет действие через ADB и переключает мышь
  на ADB.
